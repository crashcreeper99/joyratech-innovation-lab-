# PCB and Embedded Systems

**Status:** skill building

This area documents the transition from breadboard experiments to reliable embedded prototypes.

## Learning sequence

1. Read schematics and component datasheets.
2. Build and measure a stable power section.
3. Create a small schematic around a proven circuit.
4. Perform electrical-rule and design-rule checks.
5. Order, assemble, inspect, and bring up a simple board.
6. Write testable firmware with clear states and error handling.
7. Measure the board against its requirements.
8. Revise the design from evidence.

## Minimum documentation

- project purpose and requirements;
- block diagram;
- bill of materials with part sources;
- schematic and board revision;
- power and signal assumptions;
- bring-up checklist;
- test results and known issues;
- safety and IP review before public release.

The first custom board should be small and replace a circuit that already works on a breadboard.
