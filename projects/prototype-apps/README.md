# Prototype Apps

**Status:** planning

This area holds small applications that support Joyratech hardware and make demonstrations understandable.

## Possible roles

- configure a device;
- show live sensor or connection state;
- record experiment data;
- provide accessible controls;
- demonstrate one end-to-end user workflow.

## First build standard

Every app should have:

- one named user;
- one primary task;
- clear status and error feedback;
- a simple setup path;
- no stored secrets in the repository;
- a short test plan and demonstration.

A polished screen is not proof of a working product. App work should connect to a validated project requirement.
